# Mate de por Medio

Un pequeño mundo ilustrado alrededor del ritual de tomar mate. La experiencia busca ser apacible, artesanal, accesible y autónoma: una mesa matera como punto de partida, historias, curiosidades y un pueblo ficticio inspirado en la vida cotidiana.

## Publicación
Sitio estático para GitHub Pages. No necesita servidor, base de datos, cuenta de visitante ni dependencias de pago.

- index.html: estructura y escena ilustrada.
- styles.css: diseño adaptable y animaciones suaves.
- app.js: ritual interactivo, cuentos, curiosidades, personajes y cajita solidaria.

## Pendiente antes de publicar una colaboración real
Configurar el alias correcto de Elías en la cajita solidaria. No se publica ningún alias inventado ni se bloquea contenido por colaborar.

## Notas
- El sonido no está incorporado en esta primera versión.
- Las historias de los habitantes son ficción.
- Las curiosidades locales deben verificarse y acreditarse antes de ampliar el contenido histórico.
