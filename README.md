# El rinconcito de Elías · Mate de por Medio

Rincón digital independiente, cálido y sin apuro: cuentos breves, curiosidades materas, pequeñas pausas y regalos digitales gratuitos. Funciona sin cuentas ni atención diaria.

## Experiencia
- Bienvenida con ilustración artesanal y navegación sencilla.
- Cuentos breves, curiosidades y consejos que se pueden recorrer dentro de la página.
- Tres regalos SVG para pintar, compartir o usar como fondo.
- Cajita de colaboración voluntaria, visible desde el margen y explicada con claridad.
- Diseño adaptable a móvil y escritorio, con foco de teclado visible y movimiento reducido respetado.

## Archivos
- `index.html`: estructura y contenido visible.
- `styles.css`: sistema visual y adaptación responsive.
- `content.js`: biblioteca editorial.
- `app.js`: interacciones y alias voluntario.
- `descargas/`: archivos SVG descargables.

## Colaboración voluntaria
El alias configurado en `app.js` es **`ocarina.guitarra`**. El botón intenta copiarlo al portapapeles; si el navegador no lo permite, se puede copiar manualmente. Colaborar es opcional y nunca condiciona el acceso al contenido. La página no procesa ni verifica transferencias.

## Publicación
Sitio estático para GitHub Pages, sin base de datos ni servidor propio. Un commit no garantiza por sí solo que Pages ya haya terminado de publicar: conviene revisar la página en un navegador real, en escritorio y móvil, además de probar los botones y descargas.
