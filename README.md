# Tomar mates con Elías

Un pequeño fogón digital desde San Patricio del Chañar. Todo nace del ritual matero: preparar el agua, cebar, compartir una charla, mirar el valle y dejar que una historia acompañe el momento.

## Experiencia
- Portada ilustrada y fogoncito como corazón visual.
- Cuentitos originales, curiosidades del valle y miradas tranquilas enmarcadas en la ronda del mate.
- Pinturitas originales inspiradas en mates, pava, paisaje y costumbres para guardar e imprimir.
- Búsqueda y filtros locales, botón «Sorprendeme», lectura en ventana y descargas directas.
- Los hechos históricos incluyen fuente visible; los cuentos se identifican como ficción.
- Invitación a colaborar de forma voluntaria, sin pago obligatorio ni contenido bloqueado. El alias se publicará una vez confirmado por Elías.

## Estructura técnica
- `index.html`: portada, fogoncito, biblioteca y sección de colaboración.
- `css/styles.css`: paleta cálida y pintada, accesibilidad y diseño adaptable.
- `js/app.js`: búsqueda, filtros, lectura, navegación y sorpresa aleatoria.
- `js/contenido.js`: catálogo editorial separado del diseño.
- `assets/pinturitas/`: dibujos SVG para descargar e imprimir.
- `assets/casita-chanar.svg`: ilustración principal.

## Límites deliberados
No hay cuentas, comentarios, formularios, analítica, rastreo, reproducción automática, base de datos, backend ni servicios pagos. No requiere que Elías esté conectado. La colaboración es voluntaria y no condiciona el acceso.

## Revisión antes de publicar
- Comprobar renderizado real en navegador y celular.
- Descargar e imprimir cada SVG.
- Verificar enlaces de fuentes y mantener la distinción entre hechos y relatos.
- Confirmar el alias antes de mostrarlo como dato para transferencias.
- Activar GitHub Pages solo después de la revisión visual.
