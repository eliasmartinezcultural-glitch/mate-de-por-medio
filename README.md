# Tomar mates con Elías

Un rincón personal, corto y acogedor desde San Patricio del Chañar. Historias, pequeñas curiosidades, miradas y dibujos para disfrutar sin apuro.

## Experiencia
- Una portada ilustrada y una biblioteca sencilla.
- 14 piezas iniciales entre cuentos originales, miradas personales, pequeñas propuestas, curiosidades y dibujos.
- Búsqueda y filtros locales, botón «Sorprendeme», lectura en ventana y descargas directas.
- Las afirmaciones históricas llevan una fuente visible; la ficción está identificada.
- Los dibujos originales son SVG y se pueden guardar e imprimir.

## Estructura técnica
- `index.html`: portada y estructura visible.
- `css/styles.css`: identidad visual, accesibilidad y adaptación responsive.
- `js/app.js`: búsqueda, filtros, lectura, navegación y sorpresa aleatoria.
- `js/contenido.js`: catálogo editorial separado del diseño.
- `assets/pinturitas/`: dibujos para imprimir.
- `assets/casita-chanar.svg`: ilustración principal.

## Límites deliberados
No hay cuentas, comentarios, formularios, analítica, rastreo, reproducción automática, base de datos, backend ni servicios pagos. No requiere que Elías esté conectado.

## Revisión antes de publicar
- Comprobar renderizado real en navegador y celular.
- Descargar e imprimir cada SVG.
- Verificar enlaces de fuentes y mantener la distinción entre hechos y relatos.
- Activar GitHub Pages solo después de la revisión visual.
