# Mate de por Medio

Una página cálida y sencilla para hacer una pausa, leer historias breves, descubrir curiosidades y descargar pequeños regalos. Sitio estático pensado para GitHub Pages, sin cuentas ni base de datos.

## Estructura
- `index.html`: experiencia y estructura semántica.
- `styles.css`: identidad visual adaptable a celulares, tabletas y computadoras.
- `app.js`: historias, curiosidades, pausas y botón para copiar el alias.
- `descargas/`: tres regalos digitales en SVG.

## Colaboración voluntaria
Alias configurado: `ocarina.guitarra`. La colaboración es opcional. La página no procesa ni verifica transferencias; el contenido y las descargas no están condicionados a colaborar.

## Publicación y pruebas
GitHub Pages puede tardar un poco en mostrar los cambios. Probar en móvil y escritorio, navegar por teclado, activar cada botón y descargar los tres regalos.
