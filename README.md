# Tomar mates con Elías

Un rinconcito personal para compartir pequeñas historias, curiosidades, cuentitos y pinturitas inspiradas en San Patricio del Chañar.

## Estructura

- `index.html`: página de entrada.
- `css/styles.css`: estilos visuales.
- `js/app.js`: comportamiento e interacción.
- `js/contenido.js`: contenido editorial separado del diseño.
- `assets/`: ilustraciones y recursos gráficos.
- `descargas/pinturitas/`: archivos imprimibles gratuitos.

## Principios

- Sitio estático: HTML, CSS y JavaScript.
- Sin cuentas, base de datos, comentarios ni formularios que requieran respuesta.
- Todo el contenido es gratuito; cualquier colaboración será opcional.
- Verificar los datos históricos y distinguir claramente la ficción.
- No publicar hasta revisar diseño, enlaces, descargas y adaptación móvil.

## Publicación

La activación de GitHub Pages se realizará después de completar y probar la primera versión.
